# server — `@devdigest/api`

Fastify 5 REST/SSE API on **:3001**. Drizzle ORM + Postgres (pgvector), Zod, TypeScript (ESM),
run with `tsx`. pnpm. See root `CLAUDE.md` for the stack overview and `README.md` for how the
whole thing boots.

## Session protocol (engineering-insights loop)
- **Start:** before touching this package, read `server/INSIGHTS.md` and treat it as
  high-confidence guidance. Summarize the top relevant points to confirm an active read.
- **End:** run `/engineering-insights` to capture non-obvious discoveries into
  `server/INSIGHTS.md`. Writes are **append-only** (anchored `Edit`, never `Write`); if nothing
  substantial came up, write nothing — but don't skip the check.

## Layout
- `src/modules/**` — feature modules (`pulls`, `reviews`, `repos`, `repo-intel`, `polling`,
  `agents`, `workspace`, `settings`, `_shared`). Each is a Fastify plugin at
  `modules/<name>/routes.ts`.
- `src/platform/**` — cross-cutting wiring: `container.ts` (DI), `config.ts`, `sse.ts` (RunBus),
  `errors.ts`, `grounding.ts`, `price-book.ts`, `model-router.ts`, `jobs.ts`, `trace-builder.ts`.
- `src/adapters/**` — concrete impls of the `@devdigest/shared` ports (secrets, auth, github,
  git, codeindex, llm, embedder, depgraph, tokenizer).
- `src/db/**` — `schema/**` (Drizzle tables), `migrations/**` (generated SQL), `seed.ts`.

## Conventions (not obvious from the code)
- **Static module registry.** New feature = new `modules/<name>/routes.ts` + one import + one
  entry in `src/modules/index.ts`. There is deliberately **no filesystem autoload** — the static
  path works identically under `tsx`, the bundler, and vitest.
- **DI via `src/platform/container.ts`.** Services depend on the **interfaces** exported from
  `@devdigest/shared`, not on concrete adapter classes. Tests inject mocks via
  `ContainerOverrides`. Adapters are resolved lazily through `SecretsProvider`, so the app boots
  with **no** LLM keys — a key is only needed to run a review or enable embeddings.
- **ESM everywhere:** relative imports carry the `.js` extension (even from `.ts` source).
- **Migrations are explicit:** edit `db/schema/*.ts`, then `pnpm db:generate` (drizzle-kit) to
  emit `NNNN_*.sql`, then `pnpm db:migrate`. Never hand-write or hand-edit migration SQL.
- `pnpm dev | test | typecheck`. Server tests use Vitest + testcontainers.

## Do-not-touch
- `src/db/migrations/**` — generated by drizzle-kit; regenerate, don't hand-edit.
- `src/vendor/**` — vendored/synced copies (incl. `vendor/shared/contracts`, duplicated with
  `client/`). Change the upstream source, not the copy in place.
- `clones/**` — cloned-repo **fixtures** (incl. a nested `CLAUDE.md`). Not app code — never edit.
